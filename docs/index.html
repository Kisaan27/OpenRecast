Installing

  1. Open the downloaded OpenRecast .dmg and drag OpenRecast into Applications.
  2. On first launch macOS will block it. Go to System Settings → Privacy & Security and click Open Anyway.
  3. That's it. Every file you work on stays on your Mac.
